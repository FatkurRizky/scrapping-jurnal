# Scholar Search — Frontend

Frontend React 19 + Vite + Tailwind CSS v4 untuk aplikasi pencarian jurnal akademik.

Dokumentasi lengkap (setup, API, roadmap) ada di [README utama](../README.md).

## Menjalankan

```bash
npm install
npm run dev     # dev server di http://localhost:5173
npm run build   # build production
npm run lint    # eslint
```

> Backend harus jalan dulu di port 5000. Lihat [README utama](../README.md).
